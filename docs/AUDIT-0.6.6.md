## 发现并修复的问题

- 文件输入原来在能力检查阶段被拒绝；现支持 PDF/DOC/DOCX 转为同账号原生附件。图片 detail=original 规范化为 high，字节不变。
- MIME 文件名原来经 Go %q 编码，合法 NBSP、零宽空格会变成字面转义；现按 MIME 规则转义并保留 UTF-8。原生和内嵌文件名统一拒绝 Unicode 控制字符及无效 UTF-8。
- 检测解析原来可能使用 user/tool/reasoning 或非文本块的内容，并忽略后续 choice 未完成或互相矛盾的回答；现只采用 assistant 文本，检查所有 choice，冲突作为检测错误，不归为正常或疑似。
- 单号/一键检测的选中状态提示与 403 自动停用不一致，以及部分完成时摘要误写“检测完成”；现显示真实选择变化与完成状态。
- UI 补充真实请求消耗额度、固定探针局限和 Word 工具执行责任，避免把附件转发或单题回答描述为完整文档执行器或全面能力测评。
- 源码导出原白名单会遗漏新增 PDF/DOCX 回归样本，导致解压后测试缺文件；现只精确放行两个合成样本，并检查 ZIP 中字节及其他文档/凭据的排除边界。
