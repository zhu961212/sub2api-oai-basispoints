# 0.5.19：六模型选择

日期：2026-09-26。插件 ID：local.oai-basispoints。

## 配置与转发

配置页提供六个独立的模型复选框：`gpt-6-astra`、`gpt-5.6-sol`、`gpt-6-sol`、`gpt-6-luna`、`gpt-5.6-terra`、`gpt-5.6-luna`。默认只勾选 Astra 与 5.6 Sol。

仅所选模型在命中宿主灰度、符合账号白名单时转发到 Basis Points，上游保持本次请求的模型名。未选模型、未知模型与旧 `-excel` 别名原样透传到宿主上游。

- 模型全部取消勾选：所有模型全部透传。
- 账号全部取消勾选：不限制账号，仍按模型选择转发。
- 点击保存后会重新读取并核对模型和账号选择；加载或保存期间锁定控件，失败保留当前选择，状态轮询不覆盖未保存修改。

采用最新配置字段 `enabled_models` 与 `account_ids`，不保留旧模型、旧图片或单账号配置迁移。全新安装的最简选择配置为：

```json
{
  "enabled_models": ["gpt-6-astra", "gpt-5.6-sol"],
  "account_ids": []
}
```
