# 0.5.17 缓存与项目发布优化

日期：2026-09-26（本地）。交流群：**1107265919**。

## 变更

- 原生工具历史、工具目录和响应上下文改为有容量与字节预算的 LRU，2 小时闲置过期，降低读取锁竞争。
- 修复工具历史缓存的大整数精度；保持会话隔离、目录清空和并发增量发现逻辑。
- 账号代理连接池限制 128 项，5 分钟闲置惰性回收；普通账号/工具配置保存保留连接。
- 账号目录合并并发刷新，有旧快照时立即返回，失败短暂退避；宿主重连或关闭不接受迟到结果。
- 图片请求内去重减少重复摘要，完整内容缓存命中跳过重复 Base64 扫描；匿名图片请求不再挤占可复用缓存。
- 插件卡片介绍、配置页、README 与 GitHub 上传文档加入交流群 1107265919。
- 增加源码导出脚本及边界测试、GitHub CI；保留自动图片上传和首轮未知工具纠正。

缓存配额、过期行为与本地测量详见 [CACHE.md](CACHE.md)。本地图片重复处理约减少 57.9% 开销，目录缓存读取约从 0.62ms 降至 0.07ms；不代表上游推理或公网响应速度。
