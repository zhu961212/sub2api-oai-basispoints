# 请求时区功能已移除（0.6.11）

从 0.6.11 起，插件不再提供“请求时区跟随出口 IP”。配置页开关、IP 时区查询、查询缓存及请求环境日期/时区改写均已移除。原生 Codex、BPS 业务和原生降智检测都不会为此功能请求外部定位服务。

## 升级行为

- 旧配置的 native_timezone_by_ip 布尔值和 null 仅用于兼容读取；加载后丢弃，新的配置响应、保存内容及诊断快照不再输出此字段。旧字段类型错误仍拒绝，不放松其他未知字段校验。
- 请求中已有的时区、日期和普通工具参数由客户端提供，插件不再按出口 IP 修改或补充。BPS 仍执行既有协议适配，此变化不承诺整个请求逐字节透传。
- 旧自动检测记录若启用了时区修改，保留已确认的业务路由，但不把旧待确认结果与移除功能后的结果混合计算；重新安排检测后仍按既有连续确认规则切换。
- 自动原生检测及 BPS 切换功能保留，与本次删除无关。无需主动调用真实账号即可完成配置迁移。

本页保留原路径，供旧版本发行记录链接查阅；0.6.7–0.6.10 的时区开关说明仅描述对应历史版本，不适用于 0.6.11。

本次发行内容和最终验证记录见 [0.6.11 发布说明](release-0.6.11-2026-09-30.md)。
