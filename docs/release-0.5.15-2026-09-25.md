# 0.5.15 首轮工具调用修复与图片性能优化

日期：2026-09-25。插件 ID：local.oai-basispoints。

## 首轮工具调用

针对首次对话出现 stream disconnected before completion: Basis Points returned an unknown client tool absent from the active catalog：

- 按本轮实际目录生成自定义工具的中转信封示例，明确 code.args 中的原始文本会还原为 custom_tool_call.input。描述内的 helper 仍只能通过已声明的执行器调用。
- 首次工具交互若收到一个位于输出末尾、尚未发给客户端的未知中转调用，最多追加一次纠正请求。错误调用不会执行，纠正请求保留同一账号、代理、模型、历史及图片 URL。
- 纠正等待期间保持流式心跳；沿用原响应身份和已发送文字，校验后再发出纠正工具。两次成功收集的用量按整数精度合并。
- 已有工具历史、多工具、不安全位置、参数错误或歧义目录均不放宽处理；纠正后仍非法则失败，不无限重试。

## 图片性能

- 首次图片由两次解码改为一次严格解码，并用 64 KiB 缓冲合并小块写盘。
- 同作用域、同完整内容复用已验证的临时文件；同请求重复图片避免重复处理，张数和总字节限制仍逐次计入。
- JSON 直接读取原始字节；图片协议仅比较 data: 前缀；下载移除冗余工作缓冲。工作缓冲回池前清零。
- 保持图片原始字节、精度、作用域隔离、30 分钟有效期与配额。增加跨解码块内部填充、20 MiB 边界、满容量非法输入和并发失败回收回归。

约 3 MiB 有效 PNG 的本地短基准（5 次迭代、3 组中位数）：

| 场景 | 优化前 | 优化后 | 耗时下降 |
| --- | ---: | ---: | ---: |
| 首次处理 | 32.616 ms | 17.989 ms | 44.8% |
| 同会话重发 | 14.060 ms | 10.237 ms | 27.2% |
| 同请求四张重复图片 | 73.617 ms | 17.808 ms | 75.8% |

完整方法和原始数据位置见 [性能记录](PERFORMANCE-0.5.15.md)。这些数据只测本地 Relay，不包含公网下载、JSON 解析或真实 BPS 模型识别耗时。
