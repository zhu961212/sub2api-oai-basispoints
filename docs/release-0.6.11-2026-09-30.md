# 0.6.11：移除时区改写并优化并发性能

日期：2026-09-30。插件 ID：local.oai-basispoints。沿用 oai-basispoints-v1 Ed25519 发布签名身份和原公钥。

## 用户可见变化

- 删除“请求时区跟随出口 IP”开关、定位查询及缓存、请求环境日期/时区改写；原生 Codex、BPS 和原生检测均保留客户端提供的环境。旧配置兼容加载后移除废弃字段，旧检测待确认结果安全迁移。
- 改善 64 并发突发的连接复用，复用并清零流式读取缓冲，减少请求内 JSON 编解码；完整历史、工具声明和账号/会话隔离保持原有边界。量化条件见 [性能与并发记录](PERFORMANCE-CONCURRENCY-2026-09-30.md)。
- 纳入当前工作区已完成的工具调用封装及诊断、可信会话缓存提示、缓存用量统计、附件错误脱敏修复。
- 托管联网搜索及明确的原生工具选择走原生上游；保留客户端普通工具的 BPS 适配。BPS 403 停用后按既有说明每 6 小时自动复查；BPS Retry-After 按账号、模型、端点与代理作用域短暂退避。
- BPS 模型目录实时核查仍为六个模型，没有新增或删除，见 [模型核查](BPS-MODELS-2026-09-30.md)。

## 升级与发布范围

升级后重载插件并确认版本 0.6.11。发布身份及 trusted_publishers 公钥不变，按现有宿主流程保留模型、账号、绑定和灰度配置。当前仍要求 Sub2API >=0.2.8 <0.3.0，兼容范围包括官方 0.2.8 / 0.2.9 / 0.2.11，推荐当前正式宿主 0.2.11；插件版本与宿主版本分别管理。详见 [0.2.11 兼容记录](COMPATIBILITY-0.2.11.md)。

正式附件包括 Windows/Linux amd64 签名插件、SHA-256、源码 ZIP 及其 SHA-256、原发布公钥。发布不等同于服务器部署或真实账号生成验收。

## 源码检查结果

- 本地全量 Go 测试（排除需真实账号的 TestLive）及 go vet 通过；时区移除、旧配置和旧持久状态迁移、环境原样保留、连接池和缓冲区回归检查通过。
- 308 项前端测试、JavaScript 语法检查及真实 Chrome 浏览器交互检查通过。
- 41 项 Python 工具测试及 git diff --check 通过。源码导出排除本地临时探针、账号数据和私钥。
- 最终发布须通过与提交绑定的 Linux CI/race、Windows/Linux 签名包独立验签、官方宿主 0.2.8 / 0.2.9 / 0.2.11 验收和上传回读校验；实际提交号、制品哈希及验证结果随 GitHub Release 记录。
