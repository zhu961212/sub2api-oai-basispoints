# 0.6.6：PDF / Word 附件修复与逐按钮审计

日期：2026-09-27（UTC+8）。插件 ID 为 local.oai-basispoints，沿用
oai-basispoints-v1 和原 Ed25519 发布公钥，适用 Sub2API >=0.2.8 <0.3.0。

## 修复行为

- PDF、DOC、DOCX 的 input_file 原来被能力检查拒绝。现在消息和工具结果中的内嵌文件使用当前账号、认证与代理上传同源附件接口，转为原生 file_id；已有有效原生 ID 保留。
- 文档渲染截图的 detail=original 映射为 high，保留原始图片字节、尺寸和相邻文字；关闭工具改写或响应转换时同样处理文件和该提示。
- 文件与图片共享 32 MiB 解码预算，计入历史和重复出现次数，混合内容先预检再上传。文件单个上限 20 MiB、每次最多 20 个内嵌文件；上传不落盘，不跟随重定向，错误不回显文件内容或凭据。已有文件 ID 的错误响应也脱敏。
- 修复 multipart 文件名的 Unicode 转义损坏，合法 NBSP、零宽空格等保持原始 UTF-8；补齐原生和内嵌文件名的 Unicode 控制字符及无效 UTF-8 检查。
- 保留客户端 Word/PDF 工具脚本的多行、引号、Unicode 路径与函数/custom 参数。文档创建和编辑由客户端实际工具执行，插件不内置 Word 执行器。
- 检测结果只采用 assistant 文本；用户、工具、推理与非文本块不能作为答案。相互矛盾的 output_text 或多个 choice、后续 choice 未完成都判为检测错误，避免误报正常或疑似降智。
- 从界面到后端核对所有模型/账号选择、全选、403 开关、单号和批量检测、保存、重新读取、继续查询。修正批量取消正常账号勾选的遗漏提示，单号遇 403 后的错误“不改选择”提示，及部分完成时的错误完成摘要。
- 帮助文字明确检测真实消耗额度、403 采用已保存策略、固定“苹果17”探针只反映当前规则结果，不代表全面模型能力。
- 源码 ZIP 精确纳入两个合成 PDF/DOCX 回归样本，修复解压后测试缺文件；其他文档和凭据仍被排除，二进制样本禁止行尾转换。

详见 [逐按钮审计](AUDIT-0.6.6.md) 与 [PDF / Word 输入说明](DOCUMENT-INPUT.md)。

## 检查与发布门禁

- 完整 Go 回归：go test ./... -skip TestLive -count=1 -timeout 120s；静态检查 go vet ./...；依赖 go mod verify。
- 协议与附件随机顺序重复运行 3 次；UI 语法检查 2 项、Node 单测 242 项、Python 发布工具单测 34 项。
- Chrome 真实 sandbox iframe/CSP 回归覆盖小屏、配置保存重开、scoped 与后台任务、失败恢复、超时继续查询，以及本次新增的界面语义。
- PDF 72 种与 original 截图 72 种本地组合；文件诊断脱敏 48 种组合；真实两页 PDF 和 DOCX 读写样本字节保持回归。
- Windows/Linux amd64 签名包逐成员验证 SHA-256、Ed25519 签名、发布者 ID；运行时 VCS 提交和源码 ZIP 必须对应干净提交。
- 公开上传要求同一提交的 Linux CI（含 race）通过，以及最终签名包通过原版 Sub2API 0.2.8 安装器、插件进程/RPC、多帧、诊断任务、Host 透传和 HTTP/SSE 工具失败验收。公开 Release 正文附实际结果和 CI 链接，上传后下载全部 5 个附件核对哈希。

本地与宿主验收使用合成数据，不运行 TestLive；本次不表示真实 OAuth/BPS 账号已完成文档内容识别验收，也不表示生产服务器已部署。PDF/OLE/ZIP 文件头检查不是完整格式解析，加密、损坏、超模型上下文文档仍可能被上游拒绝。file_url 不由插件下载；其他服务或账号的 file_id 不会自动迁移。

Upstream request failed 是宿主通用文案，无法只凭该文案确定所有根因。本次修复已复现的本地拒绝和传输问题，真实上游失败继续保留错误状态，不伪造成功。

## 安装

1. 沿用当前发行线的全新安装流程：停用并卸载旧插件，旧配置随卸载删除。
2. 上传 local.oai-basispoints-0.6.6.s2plugin 签名包。
3. 重新配置模型、账号、403 开关、绑定与灰度比例，再启用。
4. 重新打开配置页，确认实际运行版本为 0.6.6。

本次不提供旧配置迁移；已信任的原公钥无需更换。0.6.1 继续保持撤回。
