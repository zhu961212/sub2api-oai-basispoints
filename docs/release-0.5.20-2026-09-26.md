# 0.5.20：Sub2API 官方版适配 · Excel 六模型插件

适用于 Sub2API 官方版的插件，通过 OpenAI Excel（Basis Points）官方入口使用账号可用的官方模型。支持客户端工具适配、自动图片上传和流式响应还原；账号调度、令牌生命周期及用量计费由 Sub2API 负责。

本插件由第三方维护，适配官方版宿主，不是 OpenAI 或 Sub2API 官方发布。

配置页在正常宽度下固定显示两排：

| 第一列 | 第二列 | 第三列 |
| --- | --- | --- |
| gpt-6-astra | gpt-6-sol | gpt-6-luna |
| gpt-5.6-sol | gpt-5.6-terra | gpt-5.6-luna |

默认勾选 `gpt-6-astra` 与 `gpt-5.6-sol`。视觉顺序与键盘顺序一致；窄屏改为单列，两个系列之间留有分隔。

仅已选模型在命中灰度且符合账号白名单时走 BPS，上游保留请求模型名。模型全部取消勾选表示全部透传；账号留空表示不限制账号。配置使用最新的 `enabled_models` 与 `account_ids`，安装后选择并保存，页面会重新读取确认。

已通过 115 项 UI 测试、真实 Chrome 沙箱保存回读测试、Go 回归和静态检查，并检查正常与窄屏界面截图。此前 0.5.19 的六模型真实插件转发均返回 HTTP 200、对应模型名和完整客户端流，详见 [六模型实测](release-0.5.19-2026-09-26.md)；本次介绍与布局发布未重复调用真实上游。
