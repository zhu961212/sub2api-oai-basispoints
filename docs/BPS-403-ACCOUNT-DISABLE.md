# BPS 403 自动取消账号选择

日期：2026-09-26。最初在 0.5.25 工作区实现，纳入 0.5.26 发行；最终验证见 [0.5.26 记录](release-0.5.26-2026-09-26.md)。

2026-09-27：0.5.27 增加可保存的自动停用开关，沿用原停用与恢复记录。

## 最终规则

配置页提供“403 自动停用”开关，对应 `bps_auto_disable_on_403`。默认开启；旧配置未包含该字段时继续开启，显式保存 `false` 后关闭。

开关开启时，同一账号收到一次明确的 BPS HTTP 403，即立即停用该账号的 BPS 转发。无需特定错误码，不累计次数，也没有时间窗口。空正文、普通文本或任意错误码的 HTTP 403 均适用。

开关关闭后，新的 403 仍作为本次请求的失败返回，但不再生成或更新该账号的停用记录。普通推理、图片附件、工具纠正和主动检测在同一记录入口检查当前开关，已经发出的请求也遵循 403 到达时已保存的开关值。关闭开关不会自动恢复之前停用的账号，也不会删除历史记录；恢复仍需明确重新勾选该账号并保存。重新开启开关后，后续明确 403 又会触发停用。

- 普通推理、图片附件上传、工具纠正请求和主动账号检测都使用同一规则。
- HTTP 200 的 JSON/SSE 如果在错误上下文中明确携带 status/status_code=403，也会停用。
- 仅在错误文字里提到 forbidden、permission、HTTP403，或普通输出/工具参数中的 403，不作为停用依据。
- 401、429 及其他状态不触发该规则；宿主原生 Codex 透传返回的 403 不触发。
- 一个请求的重复错误事件只执行一次停用；只影响本次请求实际使用的账号 ID。旧宿主未提供有效账号 ID 时，不猜测要停用哪个账号。

## 生效与恢复

开关开启时，403 到达后先更新进程内路由状态，后续请求立即走原有未选账号的宿主透传路径。不会把已经失败的当前请求自动重放到另一个账号，也不会修改宿主账号的 active、可调度或全局限流状态。

配置页在下一次状态刷新时取消勾选，显示“BPS 已禁用（HTTP 403）”。停用不依赖页面打开：后台已经生效。普通状态轮询保持只读；用户之后保存配置时，账号选择与排除列表会合并自动停用结果。

如需恢复，明确重新勾选该账号并保存。页面会确认对应的当前停用标识；再次出现 403 会生成新的标识并重新取消选择。旧配置重放、普通保存、检测收尾及保存失败时宿主回滚，不会误解除新发生的停用。

旧白名单只剩被停用账号、又暂时读取不到账号目录时，保存保留原白名单边界，由独立停用记录阻挡该账号，避免“空白名单表示全部放行”的旧语义造成误接入。

## 持久化与异常

- 使用宿主提供的、按插件隔离的 KV 保存独立账号记录，TTL=0；记录仅含账号 ID、随机 block_id、http_403 原因和状态，不含凭据或错误正文。
- 重启时加载停用记录，超过 1000 条时按前缀分批读取，避免宿主 KVList 上限截断。成功加载后不定时全量查询，正常请求只查内存。
- 存储加载期间或加载失败时，不贸然放行尚未确认状态的 BPS 请求；Health 仍符合宿主初始化契约。
- 写入失败时该账号仍在当前进程停用，并退避重试；页面显示持久化异常。旧宿主没有 HostService 时只能保留进程内状态，不能保证重启后保留。
- KV 的跨服务器和断电持久性依赖宿主 Redis 部署；本次没有实现多运行副本间实时广播同步。

`bps_auto_disable_on_403` 是布尔策略字段，规范化配置始终包含它，确保 `false` 经保存、回读和重启后不会退回默认开启。`bps_reenabled_accounts` 仅用于保存用户对某个 block_id 的明确恢复确认。ApplyConfig 不删除 KV 标记，因此兼容宿主先 Apply、持久化失败后回滚旧配置的流程。

## 本地验证

- 完整离线 Go 回归及 go vet 通过。
- 首次任意 HTTP 403、JSON/SSE 明确 403、附件、工具纠正、主动检测均覆盖；后续透传与账号隔离通过。
- 401/429、普通正文里的 403、关键词错误、原生透传 403 均有不误停用的反例。
- KV 重启恢复、保存回滚、手动恢复后再次 403、并发写入、慢加载、重绑定和 1251 条记录完整加载通过。
- 开关缺省开启、显式关闭配置往返、关闭时 HTTP/JSON/SSE 403 不改路由、不创建 KV 记录、历史记录与重启保留、明确恢复和重新开启后再次停用均有回归覆盖。
- 配置页自动取消、手动恢复、新停用覆盖旧待恢复、检测收尾、保存失败及旧白名单兼容测试通过；真实 Chrome 沙箱保存/重开测试通过。
- 本机缺少可用的 CGO C 编译器，未运行 Go race；普通并发回归已重复验证。

发布与验证结果以 [0.5.26 记录](release-0.5.26-2026-09-26.md) 为准；没有自动部署到生产服务器。
