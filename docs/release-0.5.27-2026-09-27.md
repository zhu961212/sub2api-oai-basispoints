# 0.5.27：账号 ID、403 开关与单账号检测修复

日期：2026-09-27（UTC+8）。插件 ID 保持 local.oai-basispoints；签名身份沿用 oai-basispoints-v1 和原 Ed25519 发布公钥。

## 本次更新

- 账号列表显示完整账号 ID，不再截断名称。同名账号的显示、按钮与检测结果均按 ID 对应。
- 新增“403 自动停用”按钮，默认开启，切换后保存生效；保存会重新读取并核对状态。
- 配置字段 bps_auto_disable_on_403 关闭后，普通请求、附件、工具纠正和主动检测中的新 BPS 403 不再生成停用记录；已存在的停用记录保留，仍需明确重新勾选账号并保存恢复。进行中的请求采用 403 到达时已应用的开关值。
- 修复 JSON/SSE 外层失败或未完成响应包含部分答案时可能被当作正常或疑似降智的错误。鉴权失败、限流、无凭据、跳过和未完成响应均不参与降智判断。
- 单账号检测只请求目标账号，使用该账号凭据与代理，仅返回该账号结果，保留账号选择、模型与排除名单。现有“苹果17”规则保持不变，属于自定义筛选，不是通用智力测评。

## 覆盖安装

针对本地对照的 Sub2API 0.2.8，沿用相同插件 ID 可以更新安装：

1. 在插件管理页先停用旧版，并确认插件绑定已停用。正在启用的插件或绑定会阻止更新安装。
2. 上传本次签名安装包。已有 trusted_publishers 中的原公钥无需更换。
3. 安装保留插件记录 ID 与加密配置；插件 KV 命名空间按插件 ID 保留，因此已有 403 停用记录不会自动清除。
4. 更新会重建绑定，默认处于停用状态，灰度比例重置为 100%。先重新设置所需灰度比例，再重新启用插件和绑定。不要假定原启用状态或灰度比例会自动保留。
5. 重新打开配置页，确认运行版本 0.5.27、完整账号 ID、账号/模型选择和“403 自动停用”开关状态。
