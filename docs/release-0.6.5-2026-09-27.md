# 0.6.5：缓存隔离、上下文一致性与工具纠正超时

日期：2026-09-27（UTC+8）。插件 ID 为 local.oai-basispoints，沿用
oai-basispoints-v1 和原 Ed25519 发布公钥，适用 Sub2API >=0.2.8 <0.3.0。

## 修复行为

- 宿主账号指纹可能把 session_id 收敛为账号级固定值。工具目录、原生调用
  回放和响应映射改为绑定可信 conversation_id 与本次调度账号，避免不同
  对话或账号共用上下文。图片缓存使用同一套可信请求头解析规则。
- 缺少可信会话或请求头包含冲突值时，不读写跨请求上下文缓存；正文别名
  和响应编号不能绕过此限制。当前请求的完整历史、工具结果和声明保持完整，
  不按重复文本裁剪历史。previous_response_id 仍不能替代完整历史。
- 迟到响应不再恢复已经过期或被淘汰的工具目录，避免恢复已撤销的工具。
  新请求仍可显式更新目录；在途请求按发出时的冻结快照完成校验。
- 仅启用响应转换、关闭请求改写时也提前冻结目录。新增 8 组真实并发回归，
  覆盖 JSON/SSE、显式/继承目录、更新/撤销；移除修复后 8 组均能复现失败。
- 缓存键与字符串值独立持有存储，避免短字符串长期保留超大原始缓冲区。
  typed containers/custom marshalers 的快照检查与标准 JSON 树一致；原有
  最终缓存容量上限保持不变，不将快照入口检查差异宣称为突破最终容量。
- 工具纠正复用原请求截止时间，并同时响应纠正回调取消。原请求取消或
  已超时后不再发出纠正请求，避免纠正阶段重新获得完整超时预算。
- 清理两个工具修复测试遗留的精确缓存条目，修复同进程乱序重复运行误报。

## 检查与产物验证

- 完整 Go 回归：go test ./... -skip TestLive -count=1 -timeout 120s。
- Go 静态检查：go vet ./...；模块校验：go mod verify。
- 协议乱序重复回归：go test ./internal/protocol -shuffle=on -count=3。
- UI 语法检查 2 项，Node 单测 237 项，Python 发布工具单测 32 项。
- 真实 Chrome 沙箱回归覆盖 305/320/900px、配置及模型重开持久化、
  scoped diagnostics 与 6 类插件后台任务场景。
- 签名安装包包括 Windows/Linux amd64；独立验证 Ed25519、发布者 ID、
  清单成员及文件 SHA-256；源码 ZIP 检查成员白名单和当前提交内容。
- 最终包需通过原版 0.2.8 宿主安装器、插件进程/RPC/多帧传输、诊断任务、
  空模型 Host 透传和继承的 HTTP/SSE 工具失败链路验收。公开 Release 正文
  附最终提交的 Linux CI 与实际签名包验收结果；上传后再下载核对每个附件。

本机 CGO_ENABLED=0、无可用 C 编译器，竞态检测由同一提交的 Linux CI 执行。
所有本地与宿主验收使用合成数据，不运行 TestLive，不代表真实 OAuth/BPS
账号验收或生产服务器已经部署，也不保证上游 prompt cache 命中率提升。
本次未扩展函数参数校验的既有 JSON Schema 子集；结构化输出继续使用独立
JSON Schema 校验器，客户端执行器仍需校验其声明的完整工具参数。

## 安装

1. 沿用当前发行线的全新安装流程：停用并卸载旧插件，旧配置随卸载删除。
2. 上传 local.oai-basispoints-0.6.5.s2plugin 签名包。
3. 重新配置模型、账号、403 开关、绑定与灰度比例，再启用。
4. 重新打开配置页，确认实际运行版本为 0.6.5。

本次不提供旧配置迁移；已信任的原公钥无需更换。0.6.1 继续保持撤回。
缓存细节见 [缓存与上下文策略](CACHE.md)。
