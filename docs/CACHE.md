# 0.5.17 缓存策略与本地性能

交流群：**1107265919**。

本次优化针对插件进程内的缓存、连接池及图片预处理。它不承诺改变上游 prompt cache 命中率、模型推理时间或账单中的 cached tokens。

## 缓存边界

| 缓存 | 上限与过期 | 隔离、更新与回收 |
| --- | --- | --- |
| 原生工具历史 | 512 项 / 32 MiB 估算预算 | LRU；2 小时闲置过期；按会话及 call ID 隔离 |
| 工具目录 | 256 项 / 32 MiB 估算预算 | LRU；2 小时闲置过期；同会话增量更新原子合并 |
| 响应上下文 | 512 项 / 1 MiB 估算预算 | LRU；2 小时闲置过期；响应 ID 映射到会话 |
| 图片附件 ID | 512 项 / 上传起最多 30 分钟 | 完整内容+MIME+可信会话+账号凭据+端点的带密钥摘要；命中不续期 |
| 账号代理连接池 | 128 项 / 5 分钟闲置 | 完整代理 URL（包括凭据）隔离，LRU，淘汰只关闭空闲连接 |
| 账号目录 | 成功后 5 秒；失败退避 1 秒 | 并发共享一次最多 3 秒的刷新；已有快照立即返回；冷请求可独立取消 |

工具历史和目录的单条估算上限为 4 MiB；响应上下文单条上限为 16 KiB。预算包括内容和容器元数据估算，不是进程 RSS 或在途请求的硬上限。过期清理在后续访问时触发，不新增定时清理线程。

超大工具目录不长期缓存，显式更新会清除旧目录并保留空标记，避免旧工具恢复。缓存过期或被淘汰后，客户端应携带完整历史和所需工具目录；缓存不充当长期会话存储。

## 已修复的问题

- 原 FIFO 淘汰会清除持续使用的会话；现在按最近使用淘汰。
- 原工具历史缓存 JSON 转换会把大于 2^53 的整数变成浮点数；现在保持精确数值。
- 全局锁内反复序列化/解码会阻塞其他会话；现在只在锁内获取不可变快照，锁外复制容器并复用不可变字符串。
- 任意新代理永久增加连接池；现在有容量和闲置边界，淘汰不打断活跃请求。
- 保存账号或工具配置曾重建全部连接；现在只有网络超时设置变化时重建。
- 账号列表刷新曾持锁等待宿主 RPC，失败后连续重复查询；现在合并刷新、独立取消、失败退避。宿主重连/关闭会使旧结果失效。
- 缺少可信会话的图片请求原来写入随机作用域缓存，内容永远无法复用却会挤走有效条目；现在只做请求内去重，不写持久图片缓存。
- 重复图片原来多次计算完整摘要；现在同请求先识别相同内容。跨请求仍校验完整 HMAC，缓存未命中时仍严格检查 Base64、格式和尺寸，不降低校验。

## 本地短基准

环境：Windows/amd64，Intel Core i7-9700，8 个逻辑执行单元。基准不请求真实上游。

### 工具缓存

64 个工具的固定目录，优化前后各 2 次、每次 500ms：

| 场景 | 优化前 | 优化后 |
| --- | --- | --- |
| 目录读取 | 594–643 μs；391–395 KB/次 | 72.3–72.5 μs；109 KB/次 |
| 并发目录读取 | 667–686 μs | 40.8–42.2 μs |
| 原生调用快照读取 | 497–510 μs；248–250 KB/次 | 93–129 μs；109 KB/次 |

复现当前实现：

    go test ./internal/protocol -run "^$" -bench "BenchmarkProtocol(Catalog|Native)CacheHit" -benchmem -benchtime=500ms -count=2

### 图片预处理与缓存

1024×1024 确定性 PNG（约 3 MiB），本地模拟上传只读取请求体，不经过公网；每项 3 次、每次 150ms，取中位数：

| 场景 | 优化前 | 优化后 | 变化 |
| --- | --- | --- | --- |
| 首次一张图片 | 22.88 ms | 22.64 ms | 基本持平 |
| 同会话缓存命中 | 10.16 ms | 8.56 ms | 本地开销约减少 15.8% |
| 同请求四次重复图片 | 53.49 ms | 22.51 ms | 本地开销约减少 57.9% |

    go test ./internal/attachments -run "^$" -bench BenchmarkAttachmentRewrite -benchmem -benchtime=150ms -count=3

本地原始图片测量记录位于 dist/attachments-cache-before-0.5.17.txt 和 dist/attachments-cache-after-0.5.17.txt，不随源码包发布。短基准受调度与 GC 影响；这些数字不等于真实上传、模型响应或网络速度的提升。
