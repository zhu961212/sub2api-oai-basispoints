# 0.6.10：模型不存在错误不再触发账号限流

日期：2026-09-30。插件 ID：local.oai-basispoints。支持 Sub2API 0.2.8 / 0.2.9，沿用 oai-basispoints-v1 Ed25519 发布签名身份和原公钥。

## 修复

- HTTP 404 且明确返回 model_not_found 时，仅将当前请求记为不可重放的插件错误，不进入宿主账号／模型限流、冷却、临时禁调或自动换号路径。
- 同时覆盖 BPS 和原生透传，以及流式／非流式请求、JSON／SSE 错误体和 detail.error.error 等嵌套信封。
- 保留失败诊断和后续账号可用性；未改变真实 401、403、429 的既有处理。不会自动清除之前已保存的冷却记录，也不会使上游不可用的模型变为可用。
- 复用有界错误探测，保留未匹配响应及读取错误，兼容既有工具调用失败分类。源码 ZIP 包含新增宿主回归夹具。

## 验证与安装

修复前回归复现了 404 进入宿主冷却分支；修复后插件全量 Go 测试、静态检查及本地宿主 0.2.8 的 gRPC 错误帧／调度副作用回归通过。源码回归不等同于签名产物或生产环境验证。

正式发行附件提供 Windows amd64 / Linux amd64 签名包、配套 SHA-256、源码 ZIP 及 SHA-256、原发布公钥。最终包验签、两版本原版宿主验收、CI 和上传后下载校验的实际结果及提交编号列于 GitHub Release 正文。

安装后重载插件并确认运行版本为 0.6.10。升级前备份配置；若宿主要求卸载旧版，请先记录模型、账号、开关、绑定与灰度设置。原 trusted_publishers 公钥无需更换。发布不包含服务器部署或真实账号调用。

更多实现与复现命令见 [模型错误隔离说明](MODEL-NOT-FOUND-NO-COOLDOWN.md)。
