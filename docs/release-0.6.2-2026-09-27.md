# 0.6.2：relay 修复、原版宿主账号检测与设备功能移除

日期：2026-09-27（UTC+8）。插件 ID 为 local.oai-basispoints，签名身份沿用
oai-basispoints-v1 和原 Ed25519 公钥。适用 Sub2API >=0.2.8 <0.3.0，验证基准为 0.2.8。
0.6.1 保持撤回；本次不发布或要求安装旧版宿主补丁。

## 安装方式

本版按卸载后全新安装发布，不兼容或迁移旧版插件配置。

1. 停用并卸载旧插件；旧插件配置随卸载删除。
2. 上传本次 local.oai-basispoints-0.6.2.s2plugin 签名安装包。
3. 重新配置模型、账号、403 处理开关、宿主绑定与灰度比例，再启用插件。
4. 关闭旧配置页后重新打开，确认宿主运行版本为 0.6.2。

已有 trusted_publishers 中的原公钥无需更换。不得沿用旧配置中的
bps_device_convergence 字段，新版继续严格拒绝已删除字段。

## 本次变化

- 修复工具 relay 外层 JSON 的裸换行、制表符及非法反斜线转义恢复。
  完整字符串重复编码内的已知截断调用可进入最多一次纠正；重复键、多候选、
  冲突参数及过深包装仍拒绝，不执行不完整调用或写入重放缓存。
- 修复错误 #40445 的误换号与诊断遮蔽：invalid_tool_call 流式失败补齐
  invalid_request_error 类型，保留原错误码和消息；普通临时上游故障策略不变。
- 合成 SSE 的 custom input 保留首尾空白，空字符串也产生正确完成事件。
- 恢复逐账号和一键检测，通过现有 UI Bridge v1 准备、确认插件后台任务、
  按任务编号查询，无需修改或重新构建官方 Sub2API。
- 任务固定账号和参数，不应用表单未保存路由选择；重复确认、普通测试、回滚、
  重启不会重跑旧任务。准备超时不提交，提交超时只查询原任务。
- 移除设备收敛开关、标识派生与改写、设备缓存和相关状态字段。
  普通转发、附件与检测保持宿主当前身份和头部语义，不保留旧字段兼容层。
- 完善缓存快照隔离和附件过期清理。源码 ZIP 纳入宿主集成必需的两条固定
  测试夹具，继续排除私钥、凭据、环境文件及构建产物。
