# 0.6.7：原生自动检测、出口时区与工具/图片兼容修复

日期：2026-09-27（UTC+8）。插件 ID 为 local.oai-basispoints，沿用 oai-basispoints-v1 和原 Ed25519 发布公钥，适用 Sub2API >=0.2.8 <0.3.0。

## 本次行为

- 手动单号、手动批量和自动降智检测始终只请求原生 Codex，即使业务已经走 BPS；不检测 BPS，不使用 BPS responses_url 或业务模型映射。原生检测模型固定为 gpt-6-astra，无需配置，已移除模型输入项；旧配置或持久化任务中的模型不会覆盖固定值。
- 新增独立的“自动检测与切换”开关，默认关闭。默认每 30 分钟检测，可设置 5–1440 分钟；首次或新账号约 5–30 秒后分散检测。发现疑似降智或恢复后约 5 分钟复测，连续两次有效一致结果才切换：降智启用 BPS，恢复取消 BPS。
- 失败、跳过、未确认结果不改变有效路由；状态通过插件 KV 持久化并在重启后恢复。自动与手动检测互斥，当前按单实例使用。关闭自动并保存会停止调度、取消在途探针并保留最后有效路由，随后可手动修改。
- BPS 403 停用保护仍优先，自动检测不会解除已有 BPS 停用记录；原生探针的 403 只记为检测失败，不停用 BPS。模型选择与宿主灰度条件仍然生效。
- 新增独立的“请求时区跟随出口 IP”开关，默认关闭。原生 Codex 业务、BPS 业务以及原生检测请求，通过实际账号同一代理向 ipapi.co 查询 IANA 时区，更新模型环境上下文中的时区和当地日期。BPS 自定义 responses_url、重试及工具修复沿用该上下文。
- 时区查询不携带账号认证、业务正文或 Cookie，不跟随重定向；最长 2 秒，成功缓存 6 小时、失败缓存 5 分钟。关闭时不发起查询，失败保留原请求。配置字段继续使用 native_timezone_by_ip。
- 页面明确两个开关的独立含义，展示自动有效路由、最近结果及下次检测时间；自动模式下锁定手动账号选择，避免以旧快照覆盖后台状态。

完整规则见 [原生自动检测](AUTO-NATIVE-DEGRADATION.md)、[请求时区](NATIVE-IP-TIMEZONE.md) 和 [手动检测任务协议](PLUGIN-DIAGNOSTIC-TASKS.md)。

## 本次错误反馈

- 历史图片的 20 张限制来自插件本地校验，不是日志证明的 OpenAI 上游硬限制。本版把内嵌图片出现次数上限调整为 128；用户图片、function/custom 工具截图和重复图片统一计数，混合文档预检使用相同上限。所有历史图片保留，不截断、不压缩；单图 20 MiB、总解码 32 MiB、尺寸、请求准入和并发预算继续生效，文档仍限 20 次出现。
- 修复工具封装的多层 JSON 字符串在控制字符修复后错误消耗解包层数的问题；仍严格拒绝重复键、多个封装及超出层数限制的输入。
- 对明确声明的 function 工具，补齐参数末尾字符串漏转义时的一次上游纠正；与 custom 工具一致，必须保持同一工具身份和类型，并通过原参数 schema 校验。function 纠正只允许修复损坏的字符串字段，其余已解析参数的字段集合和值必须保持不变。未执行的损坏调用不会下发，代码与参数不会由本地猜测补齐；真正失败的上游终态不启动此纠正。
- 对与现有请求转换器兼容的完整工具历史，统一 custom_tool_call 与同 call_id 的 function_call_output 配对判断；未完成、重复、孤立或未知类型的结果仍拒绝纠正。

两条工具错误日志仅包含最终 response.failed，缺少原始工具 arguments，因此不能认定上述可复现边界就是原请求的唯一原因，也不保证所有 malformed/ambiguous 调用都可恢复。OAuth token_revoked 按用户要求不纳入本次修复。

## 发布检查与边界

发布门禁包括完整 Go 回归（跳过 TestLive）、go vet、go mod verify、UI 与 Python 工具回归、Chrome 沙箱检查，以及同一提交的 Linux CI（包含 attachments、protocol、transport 竞态检查）。

最终签名包独立校验逐成员 SHA-256、Ed25519 签名及发布者 ID，并核对包内双平台运行时、干净提交与完整源码 ZIP 一致。原版 Sub2API 0.2.8 宿主的官方安装器、进程/RPC、多帧传输、透传与 HTTP/SSE 工具失败场景使用最终签名包验收。

原生诊断六类跨进程场景使用同一提交的独立源码测试构建，通过仅测试用的 loopback 覆盖定向本地模拟端点；该构建不是正式签名运行时，测试覆盖不会进入发行包。实际通过结果与 CI 链接附在 GitHub Release 正文。上传后公开下载全部五个附件，重新比对 SHA-256。

普通测试不使用真实 OAuth/BPS 账号，不查询真实出口 IP。固定“苹果17 / iPhone 17”规则仅为启发式路由辅助，不代表通用智力测评；检测会消耗账号额度。时区改写不改变操作系统或服务端时区，不保证改善降智；分流或轮换代理的定位可能与模型请求实际出口不同，缓存也可能滞后。发布不表示已经安装到生产服务器或完成真实账号效果验收。

## 安装

1. 沿用当前发行线的全新安装流程：先记录需要保留的设置，再停用并卸载旧插件；卸载会删除旧插件配置。
2. 上传 local.oai-basispoints-0.6.7.s2plugin 签名包，原发布公钥无需更换。
3. 重新配置模型、账号、403 保护、绑定与灰度比例，再按需要分别开启自动检测和出口时区。两个新开关均默认关闭。
4. 保存并重新打开配置页，确认实际运行版本为 0.6.7。0.6.1 继续保持撤回。
