## 工具封装错误

用户报告：stream disconnected before completion: Basis Points returned a malformed or ambiguous client tool relay envelope。

本地复现了会产生同一错误的封装形式，并修复以下路径；没有读取生产失败请求，不能据此断定生产请求属于哪一种形式。

- 外层 arguments 被完整 JSON 字符串重复编码时，现在有界解码，保留工具原始输入、转义字符和大整数。最多执行四次完整 JSON 解码。
- code 中确定属于当前工具目录的单一调用被截断（缺少字符串结束引号或最后一个对象右括号）时，可请求上游重新生成一次完整调用；部分参数不被执行、猜补或写入重放缓存。
- 流式和非流式响应使用同一纠正规则。当前调用必须是尚未发送给客户端的唯一末尾工具调用；正常输出和 usage 保留。
- 显式历史必须有完整配对的调用及结果，调用 ID 不得冲突；带 opaque previous_response/conversation、未完成调用、孤立输出时不纠正。
- 重复 JSON 键、多候选、冲突参数别名、嵌套 transport 等真正歧义继续失败；重复生成仍错误时停止，避免无限重试或重复执行工具。

## 功能逐项核对

| 功能 | 与宿主约定及本次处理 |
| --- | --- |
| 插件协议与生命周期 | 五份 vendored API 文件与宿主逐行一致（磁盘换行不同）；保留先 Health 后 HostService 初始化、Apply 整份发布、关闭取消与连接池生命周期。 |
| OAuth 添加账号 | 授权码兑换使用宿主独立客户端，不经过 Forward。此前本地宿主 state 与错误展示修复独立保留，本轮不再修改宿主源码。 |
| 模型与账号选择 | 保留六模型精确选择、显式空模型全部透传、旧白名单、新账号自动接入和手动排除；旧白名单每次请求不再重复规范化和分配。 |
| 身份、代理与配置 | 继续使用宿主本次调度账号的凭据和代理；不自行刷新 token；配置发布后只读，以值快照替代每请求复制数组；连接池复用规则保留。 |
| 工具及多轮历史 | 修复上述确定性封装问题；拒绝歧义、未知辅助工具和调用 ID 冲突；保留 catalog、历史缓存的隔离与数值精度。 |
| JSON/SSE 与流式输出 | 复用读取缓冲，转换、图片和纠正路径只解析一次 SSE/JSON；已缓冲 JSON 不重复整包复制；保留字节预算、取消、终止和 usage 语义。 |
| 图片与附件 | 保留用户图片上传、工具截图原样回传、原始字节和 detail；既有附件 streaming、鉴权分区缓存、并发去重已符合宿主边界，不作无依据重写。 |
| BPS 401/403/429 | HTTP、HTTP 200 内 JSON/SSE、附件和纠正路径统一隔离 BPS 账号状态信号与配额头；原生 Codex 透传的真实限流仍保留。 |
| 主动账号检测 | 固定最多 8 个 worker，账号去重，尊重宿主 Schedulable；取消后排队账号不再解析身份；失败保留错误结果。 |
| 配置界面 | Set 查询代替重复线性查找，相同状态复用 DOM，普通轮询合并；保存后获取新状态并防止旧响应覆盖；卸载释放计时器和 observer。 |

Health 和常规 UI 轮询仍不访问模型上游。不会清除宿主已有账号冷却或错误状态。

## 性能测量

同一台 Windows amd64 / Intel i7-9700 / Go 1.27.1，GOMAXPROCS=8，每项采样 5 次，每次 300ms，取中位数。对比的是本轮优化前工作区（已包含此前 BPS 错误隔离修复）与优化后工作区，不是已发布二进制。

原始输出位于 build/perf-host-20260926/baseline.txt 与 after.txt。这些是插件本地处理耗时和分配，不代表模型生成速度、网络延迟或生产承载量。

| 优化路径 | 原耗时 → 新耗时（μs/op） | 耗时降低 | 原分配 → 新分配（B/op） |
| --- | ---: | ---: | ---: |
| 100 账号旧白名单查询 | 2.53 → 0.06 | 97.7% | 3,240 → 0 |
| 10000 账号旧白名单查询 | 372.31 → 4.53 | 98.8% | 377,472 → 0 |
| SSE 小增量，碎片读取 | 2577.89 → 124.18 | 95.2% | 4,414,925 → 134,932 |
| SSE 小增量，批量读取 | 736.24 → 184.78 | 74.9% | 535,514 → 198,667 |
| SSE 单条 512 KiB 文本 | 2824.10 → 812.23 | 71.2% | 7,456,130 → 4,791,068 |
| JSON 4 KiB 响应 | 36.75 → 8.91 | 75.8% | 45,812 → 12,172 |
| JSON 512 KiB 响应 | 2084.21 → 449.61 | 78.4% | 4,775,986 → 1,073,938 |
| 完整 SSE 转换处理链 | 3970.30 → 1339.32 | 66.3% | 5,063,900 → 667,420 |

未修改的自动排除表、catalog/native cache 与附件路径也使用同一组基准复测；微小时间变化不计为本次优化收益。全部 17 个场景的原始结果和分配次数保存在 comparison.json。图片 capability 基准只检查结构，不读取整张图片，其 MB/s 不代表图片处理吞吐。

UI 确定性回归：1000 个账号连续 5 次相同状态轮询，新增 DOM 节点与 resize 通知均为 0。400 账号检测取消用例只解析已进入的 8 个身份，余下账号不再发起解析。

本机 Forward 并发验证：转换与透传各测 1/8/32/64 并发，共 2048 个测量样本，全部通过响应归属、工具映射和终止验证，错误为 0。上游由 localhost 模拟，首段和完成段各延迟 10ms；64 并发转换路径首段 p95 为 16.596ms、完成 p95 为 27.168ms。这是波次验证，未测饱和容量、真实网络或 gRPC 进程开销。输出保存在 build/perf-host-20260926/local-forward.txt。
